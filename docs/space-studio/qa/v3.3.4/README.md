## Build provenance and verified QA

- 16 actual CAD floor triangles reprojected as ceiling at y=2.677m, 18 crown perimeter edges, no new collision; `HefuCeilingVisibility` returns ON for dining/living eye-level, OFF for top/above-building/outside cameras.
- Final GI bake: 20 `ContributeGI` fixed architectural renderers (**18 walls+1 floor+1 roof**), of which 10 serialized with individual lightmap indices, `LightmapSettings.lightmaps.Length=1`, 46 actual baked probes and 17 movable object roots retained with BlendProbes. Two duplicated original CAD wall sections (35/42) are still rendered but excluded from *static baking only*.
- Mac M4 uses Unity GPU Progressive Lightmapper (CPU backend unsupported on Apple silicon); low-res 512px atlas max, 32 direct/96 indirect samples and widened secondary UV margins. Final `gi-for-export.log` and `export-prepared.log` had **zero overlapping UV warnings**, unlike first attempts.
- `HefuRoofGiQA.Validate` PASS plus existing `HefuWallPBRRegression.Validate` PASS (wall, glass, sofa, kitchen, Luoyang solar, Style, 17 movable furniture). Unity Library `ExportPrepared` PASS, Android `:app:testDebugUnitTest` **24/24 PASS** and `:app:assembleDebug` PASS, signature and ZIP verified.

## Limitations

The screen appearance is not an objective 80% match to the supplied design rendering; we have not recreated manufacturer-quality cabinet/sofa meshes, actual curtains or a true real-world window panorama. This roof covers **dining/living/hall only**, other rooms stay open-top pending modeling and per-room bake. Baked shading is fixed; when roof becomes hidden in top-floorplan mode, lightmap geometry does not automatically rebake or change with time-of-day. Mac host / Unity build has an OpenCL/RadeonRays compositor native-crash risk if baking and exporting Android within the SAME Unity process; use separate processes (documented in the public source pack).

Mobile 30/60FPS, hardware thermal, actual saved-layout gestures, native WebRTC and glass alpha sorting are unverified until a phone connects to ADB.
