# Mobile Unity integration checklist

This project is originally generated by `HefuAndroidBuilder.Prepare`. Keep the CAD-derived source immutable.

1. Merge both checked-in `HefuSceneAtmosphere*.cs` files into the existing HefuVR Unity Editor assembly at `Assets/Hefu/Editor/`.
2. Place tree FBX variants under `Assets/Hefu/Models/OutdoorPreview/`, panorama under `Assets/Hefu/Textures/OutdoorPreview/`.
3. In `HefuAndroidBuilder.Prepare()`, immediately after:

   ```csharp
   HefuFurnitureDetailBuilder.Apply(house.transform);
   HefuPhotoMaterialFinish.Apply(house.transform);
   ```

   add:

   ```csharp
   HefuSceneAtmosphereBuilder.Apply(house.transform);
   ```

   This must execute after `HefuInteriorDoorBuilder.InsertAll(...)` and before the temporary birthday smoke-build, which has a renderer-count-leak check.
4. Export using `HefuVR.Editor.HefuUnityLibraryExport.Export` and integrate into Android native shell with `QPS_UNITY_LIBRARY_DIR` + `scripts/prepare-private-unity-library.sh`.
5. Editor QA method `HefuVR.Editor.HefuSceneAtmosphereQA.Validate` verifies 18 glass CAD windows, interactive kitchen and balcony sliding doors, 5 Blender trees, 9 distant buildings, skybox, sun from south, zero outdoor colliders, 17 movable objects.

**Do not** replace native app routing, saved layouts, original CAD, signaling, Android control protocol, or Quest spatial session data. For Quest, a separate bundle/runtime skybox compatibility pass is required before advertising these visuals in-headset.
